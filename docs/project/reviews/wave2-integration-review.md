# Wave 2 Integration Review — Chapters 11–17

**Reviewer:** Agent 16 (Quality and Integration) · **Date:** 2026-10-30 · **Scope:** QA Reviews 2 (technical accuracy, spot-check), 3 (pedagogy: cross-references), 4 (architecture: diagram/prose cross-links) and 7 (duplication and consistency) from `08-qa-plan.md`, applied *across* the Part III data chapters 11–17 and their interfaces with chapters 1–10.

**Method.** Targeted grep and reading, not a full read-through. (1) The ownership rows of 04 §4.5 and the Part III TOC were checked by measuring the word count of every non-owner passage on B-trees, WAL/buffer pool/ARIES, consistent hashing, Bloom filters, LSM trees, isolation levels, MVCC and replication-lag anomalies. (2) Numbers that recur across chapters were extracted and compared: page sizes, B+ tree fan-out and height, SSD/HDD latency and IOPS (against Ch 4 Table 4.9 and Ch 5), `fsync` latency (against Ch 6), Bloom bits-per-key and false-positive rates, DynamoDB limits, Snowflake layout, erasure-coding overhead and loss probability (against Ch 4 §4.16), and isolation defaults. (3) All 444 `§N.M[.K]` references in Ch 11–17 (about 300 of them cross-chapter) and 68 forward references from Ch 1–10 into Ch 11–17 were checked by script: Ch 1–17 targets against the actual headings, Ch 18–93 targets against `01-master-toc.md`. Then each reference was read for topic fit. All cross-chapter `Figure`/`Table` references were also resolved. (4) 36 worked examples were recomputed with `python3`, and the Python listings in `code/ch11`–`code/ch17` were re-run (see the list at the end). (5) The text was grepped against `terminology.md` and for British spellings.

**Post-edit checks.** `python3 build/qa_check.py`: 0 findings in all 17 chapters. `python3 build/build.py --chapters 11-17 --name qa --formats html`: 186 diagrams, 0 errors. `dist/qa.*` was deleted afterwards and `manuscript/appendices` was restored with `git checkout`. The build also re-synced 12 stale `diagrams/ch1x/*.mmd` sources and added 7 missing ones (fig-11-12, fig-17-11 … 17-16) from the committed chapter text. For example, `fig-13-05.mmd` in git still showed the separator "34" that the chapter now gives as "35". None of these changes come from this review's edits. Keep them, or discard them with `git checkout -- diagrams && git clean -n diagrams`.

## Remaining risks

- **Vendor limits and prices** are the most perishable facts in Part III: DynamoDB per-partition limits and prices, Elastic shard-size guidance "as of 2025", the Cassandra `num_tokens` default, the PostgreSQL 18 checksum default, and Redis HLL encoding. All of them carry "as of" tags and open verification items, but none were re-verified against primary sources here.
- **Owner numbers propagate silently.** Ch 4 §4.4.3, Ch 11 §11.8.2 and Ch 13 §13.6.1 now cite one another, so a change to page size, fill factor or entry size in any one of them must be applied to all three. The same applies to Ch 4 §4.16 → Ch 15 §15.6 (AFR 2%, T = 24 h).
- **Reference drift.** This review checked about 510 references by script (444 in Ch 11–17, 68 inbound from Ch 1–10), as wave 1 did. There is still no automated §-reference resolver in `qa_check.py`, so later renumbering in Ch 11–17 (or in the TOC for Ch 18+) would break inbound references without warning. The scratch script used here is easy to fold into `qa_check.py`.
- **Diagram sources in git were stale** (see Post-edit checks). The committed `diagrams/` tree should be regenerated, or treated as a build artifact, before the next release build.
- **Code that was not executed:** `code/ch11/listing-08` (PostgreSQL isolation demo, needs `psycopg2` and a server) and the non-Python listings (JS, SQL, Go) in `code/ch12`–`code/ch17`.
